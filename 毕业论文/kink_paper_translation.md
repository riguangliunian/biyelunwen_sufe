## 2 模型

设 Y 表示感兴趣的结果变量，X 为一元阈值变量，A ∈ {0, 1} 为二值处理指示变量，W 为 p 维额外协变量向量，可能影响结果。

我们考虑半监督设定，其中观测数据由标记数据集 L 和未标记数据集 U 组成。标记数据集包含 n 个独立观测：L = {Zᵢ = (Xᵢ, Wᵢᵀ, Aᵢ, Yᵢ)ᵀ : i = 1, …, n}。未标记数据集包含 N 个独立观测：U = {(Xⱼ, Wⱼᵀ, Aⱼ)ᵀ : j = n+1, …, n+N}，其中结果变量 Y 缺失。我们假设 L 和 U 中的数据来自相同的底层分布。在典型的半监督场景中，未标记样本量远大于标记样本量，即 N ≫ n。

我们考虑一个回归模型，该模型允许处理效应在运行变量 X 上存在单一的未知拐点（kink）。具体而言，模型定义为：

> Y = α₀ + α₁X + τA(X − δ)1(X ≥ δ) + μ(W) + ε, &emsp;&emsp; (1)

其中 α₀ 为截距，α₁ 为无处理时 X 的基线斜率，τ 表示处理组特有的拐点效应大小，δ 是处理效应可能发生变化的未知阈值（拐点），μ(W) 是捕获协变量 W 效应的未知光滑函数。误差项 ε 满足标准外生性条件 E[ε | A, X, W] = 0。

项 τA(X − δ)1(X ≥ δ) 显式地将异质性处理效应建模为运行变量 X 的函数。它确保拐点效应仅适用于处理组（A = 1），并且仅在 X 超过未知阈值 δ 时才激活。在此形式下，模型可以捕获以下场景：处理效应在阈值以下可忽略或不存在，但在超过阈值后线性增加（或减少），反映处理响应的结构性变化。

我们的主要兴趣在于检验处理是否表现出由运行变量某未知值处的结构性变化（拐点）所刻画的异质性效应。形式上，这对应于检验处理效应在所有 X 值上是均匀的原假设，与在某个未知点存在拐点的备择假设：

> H₀ : τ = 0 &emsp; vs &emsp; Hₐ : τ ≠ 0 &emsp;&emsp; (2)

在原假设下，模型退化为一个不随 X 变化的均匀处理效应的标准线性回归；而在备择假设下，存在一个子群体，其处理效应在 X 超过阈值 δ 后发生系统性变化。

## 3 方法

### 3.1 半监督双重稳健Score检验

在所有结果均被观测的完全监督设定下，检验原假设 H₀ : τ = 0 可以使用双重稳健得分函数来构造。遵循标准半参数理论，在候选阈值 δ 处第 i 个个体的得分核心分量为：

> ψ₁(Zᵢ; δ, η, ζ) = (Xᵢ − δ)1(Xᵢ ≥ δ) · {Aᵢ − π(Xᵢ, Wᵢ; η)} · {Yᵢ − h(Xᵢ, Wᵢ; ζ)} &emsp;&emsp; (3)

其中 π(Xᵢ, Wᵢ; η) = P(Aᵢ = 1 | Xᵢ, Wᵢ) 为倾向分数模型，h(Xᵢ, Wᵢ; ζ) = E[Yᵢ | Xᵢ, Wᵢ] 为 H₀ 下的基线结果回归模型。(3) 的构造保证了双重稳健性：如果倾向分数模型或基线结果模型中任一个被正确设定，则估计方程在 H₀ 下期望为零。

然而，仅依赖规模为 n 的小标记数据集 L 会导致检验统计量具有较大的方差，从而缺乏检测结构性变化的充分功效。为充分利用规模为 N 的大量未标记数据集 U，我们提出一个在两个相互关联的方面运作的效率提升策略：倾向分数的合并估计和未观测得分的非参数插补。

**首先**，我们观察到倾向分数模型 π(X, W; η) 的估计仅依赖于处理分配 A 和协变量 (X, W)，因此不需要缺失的结果 Y。因此，我们可以在整个合并数据集 L ∪ U（规模为 M = n + N）上通过最大化二项对数似然来估计 η。设 η̂ₘ 为此合并估计量。由于 M ≫ n，η̂ₘ 的估计误差相对于通常的 n^{−1/2} 收敛速度渐近可忽略，有效地消除了得分函数中方差的一个主要来源。相反，严格需要 Y 的基线结果参数 ζ 仅使用标记数据 L 进行估计，得到估计量 ζ̂ₙ。

**在精细化倾向分数估计量的基础上**，我们接下来处理未标记数据的得分函数中未观测的分量。对于 U 中第 j 个未标记观测，响应 Yⱼ 缺失。一种统计上合理的方法是将 (3) 中不可观测的 Yⱼ 替换为其条件期望 m(X, W; ζ) = E[Y | h(X, W; ζ)]。这一替换得到未标记数据的条件期望得分：

> ψ̄₁(Xⱼ, Wⱼ, Aⱼ; δ) = (Xⱼ − δ)1(Xⱼ ≥ δ) · {Aⱼ − π(Xⱼ, Wⱼ; η̂ₘ)} · {m(Xⱼ, Wⱼ; ζ) − h(Xⱼ, Wⱼ; ζ̂ₘ)} &emsp;&emsp; (4)

为非参数估计 m(X, W) 同时避免维数诅咒，我们采用单指标 Nadaraya-Watson (NW) 核估计量。单指标的一个自然且有效的选择是基线模型导出的线性预测值，Sᵢ = h(Xᵢ, Wᵢ; ζ̂ₙ)。使用标记数据集 L，在给定指标 s 和处理 a 处评估的 NW 估计量定义为：

> m̂(X, W; ζ) = Σᵢ₌₁ⁿ Yᵢ Kₕₙ(h(X, W; ζ) − h(Xᵢ, Wᵢ; ζ)) / Σᵢ₌₁ⁿ Kₕₙ(h(X, W; ζ) − h(Xᵢ, Wᵢ; ζ)) &emsp;&emsp; (5)

其中 Kₕₙ(·) = hₙ⁻¹ K(·/hₙ) 为具有带宽 hₙ 的对称核密度函数。

将 (5) 代入 (4)，得到每个未标记观测的插补得分 ψ̃₁(Xⱼ, Wⱼ, Aⱼ; δ)：

> ψ̃₁(Xⱼ, Wⱼ, Aⱼ; δ) = (Xⱼ − δ)1(Xⱼ ≥ δ) · {Aⱼ − π̂(Xⱼ, Wⱼ; η̂ₘ)} · {m̂(Xⱼ, Wⱼ; ζ̂ₘ) − h(Xⱼ, Wⱼ; ζ̂ₘ)} &emsp;&emsp; (6)

其中 ζ̂ₘ 和 η̂ₘ 表示在原假设模型下获得的干扰参数估计量。具体而言，这些参数满足以下估计方程：

> Ψ₂(η) = (1/n) Σᵢ₌₁ᴹ Dη(Xᵢ, Wᵢ) {Aᵢ − π(Xᵢ, Wᵢ; η)} = 0,
>
> Ψ₃(ζ) = (1/n) Σᵢ₌₁ⁿ Dζ(Xᵢ, Wᵢ) {Yᵢ − h(Xᵢ, Wᵢ; ζ)} + (1/N) Σⱼ₌ₙ₊₁ᴹ Dζ(Xᵢ, Wᵢ) {m̂(Xᵢ, Wᵢ; ζ) − h(Xᵢ, Wᵢ; ζ)} = 0,

其中 Dη(Xᵢ, Wᵢ) = [π(Xᵢ, Wᵢ; η){1 − π(Xᵢ, Wᵢ; η)}]⁻¹ ∂π(Xᵢ, Wᵢ; η)/∂η 和 Dζ(Xᵢ, Wᵢ) = ∂h(Xᵢ, Wᵢ; ζ)/∂ζ 分别为结果模型和倾向分数模型的基于得分的权重矩阵。值得注意的是，Dη 融合了经典逻辑回归有效得分特有的逆方差加权，确保了 π 在正确设定下的有效估计。

通过策略性地综合来自 L 的观测得分和来自 U 的插补得分，我们将半监督双重稳健得分函数定义为加权平均：

> ΨSS(δ) = (λ/n) Σᵢ₌₁ⁿ ψ₁(Zᵢ; δ, η̂ₘ, ζ̂ₙ) + ((1−λ)/N) Σⱼ₌ₙ₊₁ⁿ⁺ᴺ ψ̃₁(Xⱼ, Wⱼ, Aⱼ; δ) &emsp;&emsp; (7)

其中 λ ∈ [0, 1] 为控制两个数据集相对贡献的权重参数（例如，设 λ = n/M 为每个观测分配相等权重）。

为检验 H₀，我们扫描一系列候选阈值并构造一个最大化反对原假设证据的上确界型检验统计量：

> Tₙ,SS = sup_{δ∈D} [√n · ΨSS(δ) / σ̂SS(δ)]² &emsp;&emsp; (8)

其中 σ̂SS(δ) 为 √n·ΨSS(δ) 渐近方差的一致估计量。在备择假设 Hₐ : τ ≠ 0 下，表现出最大结构性变化的位置可以通过标准化平方得分的最大化者一致地估计，记为：

> δ̂ = arg max_{δ∈D} {n·Ψ²SS(δ) / σ̂²SS(δ)}

实践中，搜索区间 D 被限制在 X 支撑的内部，以确保在任何候选阈值两侧都有足够的样本量。利用大规模合并数据集，我们将 D 构造为合并阈值变量 {Xₖ}ᴹₖ₌₁ 的经验分位数的截断集：

> D = {δ(k) : k = ⌈Mθ⌉, …, ⌊M(1−θ)⌋}

其中 δ(k) 为合并阈值变量的第 k 个次序统计量，θ 为小的截断常数（如 θ = 0.05）。这一构造避免了边界效应并确保稳健的非参数插补。

### 3.2 渐近性质

为建立半监督检验统计量 Tₙ,SS 的渐近性质，我们必须考虑干扰参数引入的变异。在我们的设定中，这些包括参数估计量 η̂ₘ（在 M = n+N 个样本上拟合）和 ζ̂ₙ（在 n 个样本上拟合），以及非参数单指标 NW 估计量 m̂(·)。

由于 η̂ₘ 使用大规模合并数据集估计，其收敛速度为 Oₚ(M^{−1/2})。当用 √n 缩放时，其一阶估计误差变为 Oₚ(√(n/M))，若 N ≫ n 则渐近消失，若 n/N → ρ > 0 则边际贡献。因此，变异的主要来源来自 ζ 的估计和 m 的非参数插补。

设 ψ*SS(Zᵢ; δ) 为半监督调整影响函数，它将 (η̂ₘ, ζ̂ₙ, m̂) 的一阶估计误差从得分函数中投影出去。

为确保一致的渐近有效性，我们施加以下正则条件：

**(C1)** 干扰参数 ζ 和 η 的估计方程在其各自参数空间的紧子集中存在唯一解 (ζ₀, η₀)。

**(C2)** 参数估计量是渐近线性的，且其渐近方差矩阵有限且正定。

**(C3)** 条件方差 Var(Y | X, W, A) 一致有界。单指标 S = h(X, W; ζ₀) 具有连续且有界的密度。

**(C4)** 对于 D 内部的任何候选阈值 δ，概率 P(X ≥ δ) 严格大于0且小于1。

**(C5)** 样本量比率 n/N → ρ ∈ [0, ∞) 当 min(n, N) → ∞。

**(C6)** 核函数 K(·) 为有界、对称的概率密度函数。带宽 hₙ 满足 hₙ → 0、nhₙ → ∞ 和 nhₙ⁴ → 0，以防止渐近偏差主导非参数估计。

**(C7)** 函数类 {ψ*SS(·; δ) : δ ∈ D} 为 P-Donsker 类。

**注释**。条件 (C1)–(C4) 和 (C7) 是半参数双重稳健推断和经验过程的标准要求。条件 (C5) 和 (C6) 是我们半监督框架特有的。条件 (C5) 适应各种缺失数据场景，包括未标记数据占主导的极端情况（ρ = 0）。条件 (C6) 为 Nadaraya-Watson 估计量提供了标准的带宽要求，以确保一致收敛和欠光滑。

**定理 1** 在假设 (C1)–(C7) 下，假设干扰模型 π(X, W; η) 或 h(X, W; ζ) 中至少有一个被正确设定。则在原假设 H₀ : τ = 0 下，半监督检验统计量满足

> Tₙ,SS →ᵈ sup_{δ∈D} G²SS(δ)

其中 {GSS(δ) : δ ∈ D} 为零均值高斯过程，其协方差函数为

> Cov(GSS(δ₁), GSS(δ₂)) = √(E[ψ*SS(Z; δ₁)ψ*SS(Z; δ₂)]) / (E[ψ*²SS(Z; δ₁)] · E[ψ*²SS(Z; δ₂)])

定理 1 验证了所提出的检验在半监督设定下保持了双重稳健性质和正确的第一类错误控制。极限分布是高斯过程的上确界，其协方差结构考虑了 U 上的非参数插补。

引入未标记数据集的根本动机是通过减少得分函数的方差来提高检验功效。设 Σ₁(δ) = lim_{n→∞} Var((1/√n) Σᵢ₌₁ⁿ ψ₁*(Zᵢ; δ)) 为完全监督得分的渐近方差，ΣSS(δ) = lim_{n→∞} Var(√n·ΨSS(δ)) 为半监督得分的渐近方差。

**定理 2** 在与定理 1 相同的条件下，使用最优权重参数 λ = ρ/(1+ρ)（若 ρ = 0 则 λ → 0），半监督得分函数的渐近方差满足

> ΣSS(δ) = Σ₁(δ) − Δ(δ)

其中 Δ(δ) ≥ 0。此外，只要 Var(E[ψ₁(Z; δ) | X, W, A]) > 0，则 Δ(δ) > 0 严格成立。

定理 2 严格建立了效率增益。通过对未标记数据的得分使用条件期望 m(X, W, A) 进行非参数插补，我们提取了嵌入在 (X, W, A) 边缘分布中的有价值结构信息。这有效地将原始得分投影到具有更低变异性的子空间，使得 ΣSS(δ) 严格小于 Σ₁(δ)。

为从理论上量化方差缩减如何转化为增强的检验功效，我们研究检验在局部替代下的行为。

**定理 3** 在定理 1 的条件下，考虑一列相近局部替代

> H₁ₙ : τ = n^{−1/2} c₀, &emsp; c₀ ≠ 0。

则当 min(n, N) → ∞ 时，检验统计量 Tₙ,SS 依分布收敛到

> Tₙ,SS →ᵈ sup_{δ∈D} [GSS(δ) + μSS(δ)]²

其中 GSS(δ) 为定理 1 中定义的高斯过程，非中心性参数（漂移函数）μSS(δ) 为

> μSS(δ) = c₀ · E[π(X, W){1 − π(X, W)}(X − δ)(X − δ₀)1(X ≥ max{δ, δ₀})] / σSS(δ)

其中 δ₀ 表示真实的拐点位置，σSS(δ) = √ΣSS(δ)。

定理 3 为所提方法的机制提供了深刻洞见。漂移函数 μSS(δ) 的分子与完全监督检验完全相同，代表结构性变化的真实信号。然而，由于定理 2 保证 σSS(δ) < σ₁(δ)，非中心性参数 μSS(δ) 相比于其完全监督对应量严格膨胀。漂移函数的确定性上移显著增加了上确界统计量超过临界值的概率，从理论上确保了对局部替代具有显著更高的渐近功效。

### 3.3 临界值的计算

定理 1 建立的半监督检验统计量 Tₙ,SS 的渐近零分布是一个复杂高斯过程的上确界。由于其协方差结构复杂地依赖于未知的数据生成机制，解析推导临界值是不可行的。此外，传统的非参数自助法——需要在迭代中反复重新估计合并倾向分数 η̂ₘ、基线模型 ζ̂ₙ 以及重新计算单指标 NW 核估计量 m̂(·)——在未标记样本量 N 巨大时计算上是不可行的。

为克服这一计算瓶颈，我们提出一种高效的乘数自助法（扰动重抽样）来近似极限零分布。设 ψ̂*SS(Oₖ; δ) 为第 k 个观测（k = 1, …, M）调整影响函数 ψ*SS 的经验估计，其中 Oₖ 代表标记或未标记受试者的可用数据。该经验调整影响函数考虑了干扰参数的一阶估计误差（显式公式见附录）。方差估计量 σ̂²SS(δ) 使用这些调整影响函数的样本方差一致地计算。

我们生成一列独立标准正态随机变量 ξ = (ξ₁, …, ξₘ)ᵀ，它们独立于观测数据。扰动半监督检验统计量构造为：

> T*ₙ,SS = sup_{δ∈D} (1/σ̂²SS(δ)) · [√n · {(λ/n) Σᵢ₌₁ⁿ ξᵢ ψ̂*SS(Zᵢ; δ) + ((1−λ)/N) Σⱼ₌ₙ₊₁ⁿ⁺ᴺ ξⱼ ψ̂*SS(Xⱼ, Wⱼ, Aⱼ; δ)}]² &emsp;&emsp; (9)

通过反复生成独立的 {ξₖ}ᴹₖ₌₁ 集，我们可以模拟大量扰动检验统计量。T*ₙ,SS 的经验分布提供了 H₀ 下 Tₙ,SS 极限分布的一致近似。该重抽样算法的有效性由以下定理正式保证。

**定理 4** 在原假设和条件 (C1)–(C7) 下，条件于观测合并数据 L ∪ U，有

> sup_{x∈R} |P*(T*ₙ,SS ≤ x) − P(Tₙ,SS ≤ x)| →ᵖ 0

其中 P* 表示由乘数自助扰动 ξ 诱导的概率测度，T*ₙ,SS 为 (9) 中定义的扰动检验统计量。

定理 4 确保 T*ₙ,SS 的上 α 分位数 Cα 作为渐近精确的临界值。α 水平检验在 Tₙ,SS > Cα 时拒绝原假设 H₀。

为便于方法的实际实现，搜索空间 D 可以用合并阈值变量 {Xₖ}ᴹₖ₌₁ 的经验分位数导出的等距网格来近似。计算 p 值的完整过程总结在算法 1 中。

**算法 1** 半监督双重稳健检验的乘数自助法

**输入**: 标记数据 L，未标记数据 U，合并样本量 M = n + N，预定义阈值搜索空间 D，拟合的干扰参数估计量 (η̂ₘ, ζ̂ₙ, m̂)，以及大整数 B。

**输出**: 估计的 p 值。

1. 使用 (8) 计算观测检验统计量 Tₙ,SS。
2. 在网格 D 上对所有 k = 1, …, M 评估经验调整影响函数 ψ̂*SS(Oₖ; δ)。
3. 对 b = 1, 2, …, B：
   - **步骤 1**. 从标准多元正态分布 N(0, Iₘ) 中抽取扰动向量 ξ⁽ᵇ⁾ = (ξ₁⁽ᵇ⁾, …, ξₘ⁽ᵇ⁾)ᵀ。
   - **步骤 2**. 计算扰动半监督检验统计量：
     > T*ₙ,SS⁽ᵇ⁾ = sup_{δ∈D} (1/σ̂²SS(δ)) · [√n · {(λ/n) Σᵢ₌₁ⁿ ξᵢ⁽ᵇ⁾ ψ̂*SS(Zᵢ; δ) + ((1−λ)/N) Σⱼ₌ₙ₊₁ⁿ⁺ᴺ ξⱼ⁽ᵇ⁾ ψ̂*SS(Xⱼ, Wⱼ, Aⱼ; δ)}]²
4. **步骤 3**. 基于自助统计量的经验分布计算 p 值：
   > p-value = (1/B) Σᵦ₌₁ᴮ 1(T*ₙ,SS⁽ᵇ⁾ > Tₙ,SS)
